## Learning Path

A practical progression is:

1. Start with **Host Only Heist: Lab Network Setup** to understand the lab network environment.
2. Build reconnaissance skills with **Nmap Recon Relay 3**.
3. Practice web discovery using **Content Hunt Prime Web Recon**.
4. Continue with **Prime Paths Web Enumeration** and **Exposed Files Hidden Breadcrumbs**.
5. Explore proxy concepts with **Proxy Harbor** and **Proxy Tunnel Recon**.
6. Study SOCKS-related challenges using **SOCKS Secrets** and **SOCKS Shadows**.
7. Practice pivoting concepts with **Pivot Prowl**.
8. Continue with **Proxy Pivot Hotel SOCKS**.
9. Explore application security with **Prime Access CRM Compromise**.

## How to Use the Labs

Use these cybersecurity and CTF labs only in environments where you have explicit authorization.

Recommended workflow:

1. Read the individual lab objective and requirements.
2. Identify the stated target and scope.
3. Understand the available network topology.
4. Perform reconnaissance systematically.
5. Record hosts, ports, services, paths, and technologies.
6. Map findings to the security concept being practiced.
7. Test only within the authorized lab environment.
8. Document your methodology and lessons learned.
